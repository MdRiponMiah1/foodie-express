## 📖 About The Project

**FoodieExpress** is a modern food delivery landing page developed as part of an assignment for the **Ostad Full Stack Web Development course**.

The website presents delicious food categories, popular dishes, special offers, customer testimonials, and contact information through a clean and user-friendly design.

## ✨ Features

- 📱 Responsive navigation with desktop and mobile menus
- 🍕 Attractive hero section with food imagery
- 🍔 Five food categories:
  - 🍕 Pizza
  - 🍔 Burger
  - 🍝 Pasta
  - 🥤 Drinks
  - 🍰 Desserts
- ⭐ Popular dishes with images, descriptions, prices, and order links
- 🚚 Fast Delivery section
- 🥬 Fresh Ingredients section
- 💰 Affordable Prices section
- 🎉 Special offer with 20% discount on the first order
- 🔖 Discount badges on food items
- 💬 Customer testimonials section
- 📞 Clickable phone and email contact links
- 📲 Social media links with Facebook, Instagram, and WhatsApp icons
- ✨ Hover effects and smooth, responsive layouts

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| Tailwind CSS (CDN) | Styling and responsive design |
| Flexbox | Flexible layouts |
| CSS Grid | Card and section layouts |
| Inline SVG | Social media icons |

## 🖼️ Image Sources

Food images are loaded from [Unsplash](https://unsplash.com/) using external image URLs.

No local image files are required.

**Note:** An active internet connection is needed to load Tailwind CSS and external images.

## 🚀 How to Run Locally

1. **Clone the repository** or download and extract the ZIP file.
   ```bash
   git clone https://github.com/MdRiponMiah1/foodie-express.git
   ```
2. **Open the project folder**:
   ```bash
   cd foodie-express
   ```
3. **Run the website** by opening `index.html` in any modern web browser.

   You can also use the **Live Server** extension in Visual Studio Code:
   - Open the project folder in VS Code.
   - Right-click `index.html`.
   - Select **Open with Live Server**.

4. Keep an active internet connection so Tailwind CSS and the external food images can load.

No additional installation, dependencies, or build process is required.
