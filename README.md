# FoodieExpress - Food Delivery Landing Page

FoodieExpress is a modern and responsive food delivery landing page developed as part of an assignment for the Ostad Full Stack Web Development course.

The website showcases food categories, popular dishes, special offers, customer reviews, and contact information in a clean and user-friendly layout.

## Live Preview

Open `index.html` in a web browser to view the website.

## Features

- Responsive navigation bar with desktop and mobile menus
- Hero section with an attractive heading, description, and food image
- Food categories:
  - Pizza
  - Burger
  - Pasta
  - Drinks
  - Desserts
- Popular dishes with images, descriptions, prices, and order links
- Why Choose Us section:
  - Fast Delivery
  - Fresh Ingredients
  - Affordable Prices
- Special offer with a 20% first-order discount
- Discount badges on food items
- Customer reviews section
- Contact information with clickable phone and email links
- Social media links with Facebook, Instagram, and WhatsApp icons
- Hover effects and smooth, responsive layouts

## Technologies Used

- HTML5
- Tailwind CSS (CDN)
- Flexbox
- CSS Grid
- Responsive design
- Inline SVG icons

## Image Sources

Food images are loaded from [Unsplash](https://unsplash.com/) using external image URLs. No local image files are currently required.

An active internet connection is needed to load the external images and Tailwind CSS CDN.

## How to Run Locally

1. Clone or download this repository.
2. Open the `foodie-express` project folder.
3. Open `index.html` in any modern web browser.
4. Make sure your device has an internet connection to load Tailwind CSS and external images.

No additional installation or build process is required.
